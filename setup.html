Install the widget

Add BIO-GRID Audio Module from Elgato Marketplace and place it on XENEON EDGE.

02

Run the companion

Download the Runtime, put it in a permanent folder and launch it. Find its icon in the Windows notification area.

03

In iCUE Settings → Widget Access → BIO-GRID Audio Module, allow the localhost entry on port 17652.

Right-click the Runtime icon and enable Start with Windows. Keep the executable in that folder so the saved startup path stays valid.

WHEN SOMETHING NEEDS A NUDGE

Quick troubleshooting.

Audio Module says Runtime offline

Confirm the companion is running and that localhost:17652 is allowed under iCUE Settings → Widget Access. Close other companion apps that may be using the same local port, then restart the Runtime.

Start with Windows is checked, but the Runtime doesn’t start

Keep the executable in a permanent folder. Run it manually, then uncheck and recheck Start with Windows from its notification-area menu. Confirm the entry is enabled in Windows Settings → Apps → Startup. Moving or renaming the executable can break its registered path.

Artwork disappears when a song or video changes

Runtime 1.0.2 adds artwork retention and retry handling. Widget 1.1.1 adds preloading and a grace period; use both improvements when that widget update is available. Some playback apps may not supply artwork or seeking through Windows.

Command Array keys are blank

Open the Stream Deck desktop app. Enable the widget’s app access in iCUE Settings → Widget Access, press RETRY LINK in Command Array, and assign actions to its virtual device.

A sensor or FPS readout shows dashes

Select a sensor in the widget settings and confirm iCUE can see it. FPS appears only when the iCUE provider supplies a reading for the running app.

How do I update or remove the companion?

To update, exit the running Runtime, replace its executable and run the new copy. Refresh Start with Windows if the filename or folder changed. To remove it, disable Start with Windows, choose Exit, then delete the executable.
